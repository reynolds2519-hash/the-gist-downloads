# The Gist — downloads

Installers for **The Gist**, the meeting-notes app from AR Smart Tech Solutions.
The app's code is private; this repository only holds the installers and the
`latest.json` file the apps read to update themselves.

- **Windows:** [TheGist-Setup.exe](https://github.com/reynolds2519-hash/the-gist-downloads/releases/latest/download/TheGist-Setup.exe)
- **Mac (Apple Silicon):** [TheGist-mac-arm64.dmg](https://github.com/reynolds2519-hash/the-gist-downloads/releases/latest/download/TheGist-mac-arm64.dmg)

Once installed, The Gist keeps itself up to date.
